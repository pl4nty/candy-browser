# Fast action button update

Candy Browser 0.48.0-fab.1 is Candy 0.48.0 with an updated fast action button.

## Fast action button

- Turning on **Fast action button** (Settings → Gestures & controls) now replaces the address pill. The separate "Replace the address bar" switch is gone.
- The button shows Candy's logo as a monochrome mark.
- The button draws the address bar's loading outline while a page loads.
- The button hides while you scroll down and comes back when you scroll up.
- A quick tap opens the address editor. The tab count button no longer flashes first.
- Hold or slide opens the disc 30% sooner: after 280 ms by default instead of 400 ms. The disc and its items also animate 30% faster.
- Releasing on New tab vibrates once instead of twice.
