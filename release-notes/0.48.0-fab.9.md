# Safe-area header fixes

Candy Browser 0.48.0-fab.9 is 0.48.0-fab.8 with two fixes for page headers at the top of the screen.

## Fork changes

- Headers that already offset themselves with `env(safe-area-inset-top)` on pages without `viewport-fit=cover` no longer receive the status-bar inset twice. The nit.com.au top bar now sits directly below the status bar.
- On edge-to-edge pages without a `theme-color`, the status bar is filled with the header or page background, so the header reads as flush with the top of the screen. Scrolled content no longer shows through the status bar on Claude Code Docs.
