# Facebook reels fix

Candy Browser 0.48.0-fab.2 is 0.48.0-fab.1 with a fix for Facebook reels.

## Fixes

- On Facebook reels, Facebook's top bar no longer covers the "Tap to unmute" button. Pages that lock scrolling and fill the screen now sit below the status bar, so the page script can no longer slide them under their own top bar.

## Fast action button

- The fast action button changes from 0.48.0-fab.1 are included.
