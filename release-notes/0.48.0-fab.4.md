# Facebook below the status bar

Candy Browser 0.48.0-fab.4 is 0.48.0-fab.3 with Facebook kept below the status bar.

## Fixes

- Facebook now opens below the status bar by default, as if **Force safe area** were on for facebook.com. Facebook's top bar no longer covers the "Tap to unmute" button on reels. The earlier fixes worked only for some of Facebook's reel layouts.
- To draw Facebook under the status bar again, turn off **Force safe area** in the main menu on facebook.com.

## Fast action button

- The fast action button changes from 0.48.0-fab.1 are included.
