# Facebook reels fix, second try

Candy Browser 0.48.0-fab.3 is 0.48.0-fab.2 with a working fix for Facebook reels.

## Fixes

- On Facebook reels, Facebook's top bar no longer covers the "Tap to unmute" button. In 0.48.0-fab.2 the fix ran only when the page scrolled after it loaded. Facebook scrolls the page while it loads, so the fix did not run. Candy now also checks after the page loads.

## Fast action button

- The fast action button changes from 0.48.0-fab.1 are included.
