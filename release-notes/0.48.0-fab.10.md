# Status bar fill for moved headers

Candy Browser 0.48.0-fab.10 is 0.48.0-fab.9 with one more fix for page headers at the top of the screen.

## Fork changes

- A header that Candy moves below the status bar now always gets the status bar filled with its colour, even when the page names it only by class or has many navigation menus before it, and the fill stays after the page changes layout. This targets Reuters articles, which scrolled through the status bar on 0.48.0-fab.9.
