# Sites that ask for a client certificate

Candy Browser 0.48.0-fab.5 is 0.48.0-fab.4 with a fix for sites that ask for an optional client certificate.

## Fixes

- Pages on sites that ask for an optional TLS client certificate, such as www.commbank.com.au, now load. Before, they stopped loading and failed after about 30 seconds.

## Fast action button

- The fast action button changes from 0.48.0-fab.1 are included.
