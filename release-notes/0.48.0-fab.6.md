# PDF attachments download

Candy Browser 0.48.0-fab.6 is 0.48.0-fab.5 with a fix for PDFs that sites send as downloads.

## Fixes

- PDFs sent as attachments, such as Discord file links, now download like other attachments. Before, the page stopped loading and never finished.

## Fast action button

- The fast action button changes from 0.48.0-fab.1 are included.
