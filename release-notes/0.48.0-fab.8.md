# Upstream main rebase

Candy Browser 0.48.0-fab.8 is Candy's main branch at a06cbd6 with the fork's changes from 0.48.0-fab.7. Upstream has not tagged a release after 0.48.0.

## Upstream changes

- GeckoView 160.
- Native Mozilla Sync next to Candy Sync.
- Downloads can pause and resume, and Gecko transfers stay active in the background.
- Home and new-tab URLs can be configured.
- Shorter fixed inactivity lifetimes for tabs.
- Android 12 support.
- Experimental Greasy Fork installation.
- Fixes for tab overview, predictive back, sidebars below the status bar, immersive mode safe areas, localization and add-on icons.
- The client certificate fix (0.48.0-fab.5) and the PDF attachment fix (0.48.0-fab.6) are now part of upstream.
- The FluxDown integration from Candy 0.48.0 is not on upstream main yet, so it is not in this release.

## Fork changes

- The fast action button changes from 0.48.0-fab.1 are included.
- The Facebook reels unmute fix and Facebook below the status bar by default (0.48.0-fab.2 to 0.48.0-fab.4) are included.
- The load outline spins clockwise (0.48.0-fab.7).
- The tab count shows numbers up to 999, and ∞ from 1000 tabs.
